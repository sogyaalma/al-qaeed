# مراجعة بشرية للإتاحة — لم تُنفذ آليًا

هذه خطوات اعتماد **غير منفذة بشريًا في هذه الجلسة**، وليست نتائج نجاح.
اختبارات Playwright/axe والـkeyboard الآلية لا تغلق هذه القائمة.

## بيئة الاختبار المطلوبة

سجّل النظام وإصدارات المتصفح وقارئ الشاشة والعنوان الثابت للمعاينة، ثم
اللغة (`/` و`/en/`) وأي ملاحظات وأولوية واسم المراجع وتاريخ التنفيذ.
استخدم NVDA مع Firefox/Chrome على Windows، وVoiceOver مع Safari على macOS
أو iOS. Playwright WebKit على Linux ليس Safari أو VoiceOver.

## السيناريوهات

- [ ] بالـTab: ظهور skip link أولًا ووصوله إلى main، وتركيز مرئي غير محجوب.
- [ ] من قائمة landmarks/headings: تمييز navigation/main/footer، وعنوان h1
  واحد وتسلسل عناوين الأقسام دون فقد قراءة محتوى السيرة.
- [ ] العربية: النطق واتجاه RTL للأسماء والتواريخ والأرقام والمقاطع الإنجليزية؛
  الإنجليزية: LTR وقراءة المحتوى دون قلب ترتيب الخبرات.
- [ ] فتح/إغلاق mobile menu بلوحة المفاتيح وسماع حالته، وEscape وعدم حبس التركيز.
- [ ] روابط الأقسام الثمانية تقود إلى القسم الصحيح؛ تبديل اللغة يبقي القسم
  ويُعلن لغة الصفحة الجديدة؛ Back/Forward يبقيان مسارًا مفهومًا.
- [ ] قائمة المشاركة: الاسم والحالة وترتيب التركيز وEscape؛ النسخ مع رفض
  clipboard permission له إشعار مفهوم؛ لا حاجة لنشر مشاركة خارجية فعلية.
- [ ] رابط تنزيل PDF له اسم مفهوم ويحمّل الملف الصحيح؛ راجع ترتيب قراءته
  وعناوينه ووسومه **منفصلًا**؛ استخراج نص PDF لا يثبت أنه PDF/UA.
- [ ] تكبير المتصفح/النص 200% و400%، وضع portrait/landscape على جهاز حقيقي،
  وعدم فقد الوصول إلى الأزرار أو ظهور تمرير أفقي غير لازم.
- [ ] dark preference وhigh contrast على النظام، وreduced motion، مع التركيز.
- [ ] JavaScript معطل: قراءة السيرة والفهرس واللغة وPDF و404 دون أدوات ميتة.

## سجل الاعتماد

لم يُسجل اعتماد بشري حتى الآن. تضاف النتيجة الفعلية لكل بند إلى هذا الملف
أو إلى issue مراجعة يحدد البيئة والمراجع؛ لا يُؤشر بند ناجحًا بناءً على axe وحده.
حقوق المحتوى والصورة وPDF ورخصة المشروع في [قائمة المالك](UPDATE-CHECKLIST.md).
