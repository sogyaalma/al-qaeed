Divider with Text

Adding any child content flips the divider into a flex row with two flanking lines. Useful for labeling sections or introducing alternative paths like "or continue with".

Label Position

The two lines share the space evenly, which centres the label. Add nds-start or nds-end to remove one line, so the label sits flush against that edge. For finer control, cap either line with --divider-line-start or --divider-line-end and the other takes the rest. Any length or percentage works. A cap of 0 keeps the gap between the line and the label, which is the difference from the classes. The values follow writing direction, so start is the right-hand line in RTL.

Usage Guidelines

ClassDescription
nds-verticalFlips the rule to a vertical line. Stretches to the flex parent's cross axis. Spacing modifiers apply inline instead of block
nds-startRemoves the line before the label, so the label sits flush at the start and one full line follows it. Text variant only
nds-endRemoves the line after the label, so the label sits flush at the end and one full line precedes it. Text variant only
nds-mdMedium spacing around the rule
nds-lgLarge spacing around the rule
nds-xlExtra-large spacing around the rule
nds-2xl2X-large spacing around the rule
nds-3xl3X-large spacing around the rule
nds-4xl4X-large spacing around the rule
PropertyDefaultDescription
--divider--spacing-xsBlock margin applied above and below the divider. Size modifiers override this value
--divider-size2pxThickness of the rule. Applies to the element border and the pseudo-element lines in the text variant
--divider-line-startnoneCaps the length of the line before the label, so the label moves and the other line takes the rest. Text variant only. Any length or percentage works, and 0 pins the label to the start. It is a cap, not a fixed width: a container too narrow for it shrinks the line rather than overflowing. Follows writing direction, so it is the right-hand line in RTL
--divider-line-endnoneSame, for the line after the label
--divider-color--colors-alpha-black-10Color of the rule. Swaps automatically to --colors-alpha-white-10 in dark mode. Override per-instance to match surrounding surfaces
