## 1) بيئة الالتقاط الفعلية

| البند | القيمة الفعلية |
|---|---|
| المتصفح | Chromium `153.0.8010.0` (headless shell من حزمة `@sparticuz/chromium` npm — نسخة موثّقة خارج Git) |
| الأتمتة | Playwright `1.64.0` (Python) |
| الصفحة المفحوصة | حزمة `dist/` بعد `python3 tools/build.py && python3 tools/package.py` عند commit شجرة نظيفة |
| الخادم | `tools/serve.py --port 8000` (معاينة محلية بنفس رؤوس `_headers` وCSP) |
| axe-core | `4.14.0` (عبر `tests/run_checks.py` الرسمية للمشروع) |
| سكربت الالتقاط | [`capture.py`](capture.py) · سكربت التعليل [`annotate.py`](annotate.py) |

**حدود التحقق (صريحة):**
- اختُبر على Chromium واحد فقط؛ **لم** تُختبر Firefox أو WebKit أو Safari الحقيقي أو أجهزة فعلية.
- **لم** يُجرَ اختبار قارئ شاشة (VoiceOver/NVDA) أو تنقل لوحة مفاتيح موسّع يدويًا خارج ما تغطيه `run_checks.py`.
- النتائج من تشغيل محلي **دون ضغط HTTP**؛ ليست قياسات Cloudflare ولا Core Web Vitals ميدانية.
- المواقع المرجعية الخارجية فُحصت **نصيًا فقط** (fetch/search)؛ بيئة العمل بلا وصول شبكي للمتصفح فلم تُلتقط لقطات لها.
- الفحص البصري هنا = مراجعة لقطات فعلية بعين المراجع، لا مقارنة pixel-diff آلية ولا تحليل heatmap.
