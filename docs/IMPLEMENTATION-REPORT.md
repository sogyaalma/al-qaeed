## القرار

اختير **D** بعد التحقق من المصدر: اعتماد توكنات spacing/radius فقط من NDS Vanilla `v1.12.0`، المثبت على الالتزام `030d1c7ff4ab5a3092c17b93429b1ac55291ea4d`. لم يُستخدم فرع `main` المتحرك. بقيت الألوان والهوية والخطوط والمكونات والسلوك خاصة بالموقع. تفاصيل المصدر والمفاضلة في [`NDS-INTEGRATION.md`](NDS-INTEGRATION.md) و[`NDS-STRATEGIC-RE-EVALUATION.md`](NDS-STRATEGIC-RE-EVALUATION.md).

## ما نُفّذ

- أعيد تنظيم وتوسيع `assets/css/styles.css`: أدوار لونية دلالية، سلم المسافات والانحناءات، قياسات الخطوط، حاويات وقراءة، الرأس والفهرس والأزرار، الهيرو وحقائقه، الخط الزمني والبطاقات والمنشورات والتعليم والتواصل والتذييل، ونقاط الاستجابة واتجاه RTL/LTR وتقليل الحركة.
- بقي ملف الصورة المستخدم في الموقع مطابقًا لنسخته السابقة بايتًا ببايت. أزيل فقط avatar المكرر الذي كان يعرض نسخة مصغرة ومقصوصة بـCSS على الهاتف؛ لم تُستبدل الصورة أو تُعالج ملفاتها.
- أضيف `assets/css/nds-1.12-primitives.css` كمقتطف token-only مع إشعار المصدر، وحُفظ إشعار MIT في `assets/licenses/NDS-vanilla-MIT.txt`.
- عدّل `tools/build.py` لربط CSS المثبت قبل CSS المحلي في الصفحتين وصفحة 404، وأضيفت بيانات Twitter وصيغة أحجام preload للصورة، واتجاه تلقائي للقيم المختلطة. لا تغيير على نص المصدر `content/content.json` أو المسارات `/` و`/en/`.
- أضيف `tests/run_static_checks.py`، فحوص لا تحتاج اعتماديات إضافية للتحقق من مخرجات build/package، الأصول المحلية، ترتيب CSS، متغيرات NDS المستهلكة، صفحة 404، وCSP.
- حُدّثت وثائق التوكنات والدمج والتقييم وREADME/DEPLOY، مع فصل نتائج الاختبار التاريخية عن الحالة الحالية.

لم تُضف مكتبات أو أصول صورة جديدة، ولم يتغير `assets/js/main.js` أو `_headers` أو `content/content.json`. بقيت Cloudflare Pages و`dist/` وآلية fallback بلا JavaScript. لا يحتوي مقتطف NDS إلا تعريفات `:root` ولا يُدخل CSS مكونات أو سكربتات.

## الاختبارات المنفذة

| الفحص | النتيجة |
|---|---|
| `python3 tools/build.py` | نجح؛ وُلّدت الصفحات العربية والإنجليزية و404 وsitemap |
| `python3 tools/package.py` | نجح؛ أُنشئت حزمة `dist/` الساكنة |
| `python3 tests/run_static_checks.py` | **35/35 ناجحًا** على الصفحات والحزمة والأصول المحلية وCSP |
| PostCSS parser لملفي CSS | نجح؛ لا أخطاء صياغة |
| `node --check assets/js/main.js` | نجح |
| `py_compile` لأدوات البناء والاختبارات | نجح |
| `git diff --check` | لا أخطاء whitespace |
| `python3 tests/run_checks.py` | **لم يكتمل**: توقف فورًا بسبب `ModuleNotFoundError: playwright` |

لم تُشغّل اختبارات Playwright/axe، ولم تُفتح صفحة في متصفح، ولم تُلتقط لقطات جديدة. لذلك لا أدّعي تحققًا بصريًا على أجهزة أو اختبارات وصولية آلية/يدوية أو نتائج Lighthouse لهذه النسخة. تقرير `docs/TEST-REPORT.md` يحتفظ بالنتائج التاريخية ويشير بوضوح إلى تاريخها.
