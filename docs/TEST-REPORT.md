**لم يُشغَّل هنا (يلزم قبل الدمج النهائي):** اختبارات المتصفح `tests/run_checks.py` (Playwright + axe-core + Chromium) وLighthouse — غير متوفرة في هذه البيئة. ميزات هذه الدفعة تدريجية بالكامل: scrollspy لا يعمل بلا JavaScript ولا يغير شيئًا بوجوده معطلًا، وتغييرات CSS بصرية فقط. يُشترط قبل النشر: تشغيل الحزمة كاملة، ومقارنة لقطات 360/768/1440 باللغتين، وفحص الـ console من مخالفات CSP، ومراجعة Preview على Cloudflare Pages.
